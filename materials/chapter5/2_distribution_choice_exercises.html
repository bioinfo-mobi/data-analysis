Welche Verteilung passt?

Definieren Sie für jede Aufgabe die Zufallsvariable und bestimmen Sie, welche Größen fest vorgegeben sind. Begründen Sie Ihre Wahl der Verteilung. Berechnen Sie anschließend die Wahrscheinlichkeit und vergleichen Sie Ihr Ergebnis mit der Lösung.

Aufgabe 1

Messfehler eines Sensors

Der Messfehler eines Sensors hat einen Mittelwert von 0 und eine Standardabweichung von 1 Einheit. Wie groß ist die Wahrscheinlichkeit, dass der Messfehler zwischen −1 und +1 Einheit liegt?

Lösung anzeigen

Standardnormalverteilung

Z ist der Messfehler in den angegebenen Einheiten. Für die Rechnung nehmen wir eine Normalverteilung an. Mittelwert und Standardabweichung allein bestimmen die Verteilung nicht. Bei einem Mittelwert von 0 und einer Standardabweichung von 1 ergibt sich direkt die Standardnormalverteilung.

mu <- 0
sigma <- 1
untergrenze <- -1
obergrenze <- 1

ergebnis <- pnorm(obergrenze, mean = mu, sd = sigma) -
  pnorm(untergrenze, mean = mu, sd = sigma)
round(ergebnis, digits = 6)
# [1] 0.682689
Aufgabe 2

Zwölf Würfe

Ein fairer Würfel wird zwölfmal geworfen. Wie groß ist die Wahrscheinlichkeit, genau drei Sechsen zu würfeln?

Lösung anzeigen

Binomialverteilung

X ist die Anzahl der Sechsen. Die Zahl der Würfe ist auf zwölf festgelegt. Die Würfe sind unabhängig, und bei jedem Wurf beträgt die Wahrscheinlichkeit einer Sechs 1/6.

n <- 12
p <- 1/6
k <- 3

ergebnis <- dbinom(k, size = n, prob = p)
round(ergebnis, digits = 6)
# [1] 0.197396

Qualitätskontrolle

Ein Labor prüft zehn Proben. Jede Probe fällt mit einer Wahrscheinlichkeit von 5 % bei der Qualitätskontrolle durch. Wie groß ist die Wahrscheinlichkeit, dass alle Proben die Prüfung bestehen?

Lösung anzeigen

Binomialverteilung

X ist die Anzahl der Proben, die unter den zehn geprüften Proben durchfallen. Wir gehen davon aus, dass die Ergebnisse unabhängig sind und jede Probe mit derselben Wahrscheinlichkeit durchfällt.

n <- 10
p <- 0.05
k <- 0

ergebnis <- dbinom(k, size = n, prob = p)
round(ergebnis, digits = 6)

Aufgabe 7

Die dritte Sechs

Ein Kind wirft einen fairen Würfel so lange, bis es dreimal eine Sechs gewürfelt hat. Wie groß ist die Wahrscheinlichkeit, dass die dritte Sechs beim 20. Wurf fällt?

Lösung anzeigen

Negative Binomialverteilung

X ist die Anzahl der Würfe bis zur dritten Sechs. Die Zielzahl der Sechsen ist festgelegt, die Anzahl der Würfe ist zufällig. Bei unabhängigen Würfen müssen unter den ersten 19 Würfen genau zwei Sechsen sein, und beim 20. Wurf muss eine Sechs fallen.

Parameter: L = 20 Versuche insgesamt im gefragten Ereignis, k = 3 Erfolge als festes Ziel und p = 1/6 als Erfolgswahrscheinlichkeit pro Versuch. Der letzte Versuch ist der k-te Erfolg. Bis dahin gab es L − k = 17 Misserfolge. In R ist size = k.

Der Wert L bezeichnet die Versuchszahl, für die wir die Wahrscheinlichkeit berechnen. Die Versuche laufen bis zum Erreichen der Zielzahl.

L <- 20  # Gesamtzahl der Versuche im gefragten Ereignis
k <- 3   # Zielzahl der Erfolge
p <- 1/6  # Erfolgswahrscheinlichkeit pro Versuch
misserfolge <- L - k

ergebnis <- dnbinom(misserfolge, size = k, prob = p)
round(ergebnis, digits = 6)
# [1] 0.035683

Normalverteilung

X ist die Füllmenge eines Reagenzglases. Für die Rechnung nehmen wir eine Normalverteilung an. Mittelwert und Standardabweichung allein bestimmen die Verteilung nicht. 96 µL liegen zwei Standardabweichungen unter dem Mittelwert, denn (96 − 100)/2 = −2.
