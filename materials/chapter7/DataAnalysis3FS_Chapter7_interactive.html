Idea. We simulate many experiments (two groups, n per group, Student t-test). In some of them H₀ is really true (no effect), in others there is a true effect δ (in units of the SD). We know which is which – in real life we don't!
  • Start with share of true effects = 0: all H₀ true. The p-values are uniformly distributed and ≈ α of them are "significant" anyway – these are the false positives (type I errors).
  • Now set the share to e.g. 10% and δ = 0.5: among the significant results, how many are false positives? This is why "p = 0.03 means a 3% chance that H₀ is true" is wrong (Question 4): p is computed assuming H₀, it is P(data at least this extreme | H₀), not P(H₀ | data).
  • Increase n: the power (share of true effects detected) goes up.

  • With a small true difference D (say 1–2 kg) and SD = 10 kg, what n do you need to become significant? The effect size (Cohen's d = difference / SD) hardly changes with n – only the p-value does.

Idea. Question 5: is the data (approximately) normal? Compare the QQ-plot and the Shapiro-Wilk test (H₀: data normally distributed) for different populations and sample sizes.

Idea. In tab 2 we saw: if H₀ is true and the assumptions of the test hold, p-values are uniformly distributed between 0 and 1, so exactly a share α of them falls below α. The t-test assumes normally distributed data. What happens if the data are not normal? We simulate many experiments in which H₀ is true (μ₀ = true population mean, or both groups drawn from the same population) and look at the p-values.
  • Normal population: flat histogram, ≈ 5% of p-values below 0.05 – the reference.
  • Exponential or lognormal, one-sample test, n = 10: the histogram is no longer flat – too many small p-values (≈ 10–16% "significant" instead of 5%). With a one-sided alternative the effect is even stronger ("less") or reversed ("greater"). The right panel shows why: the t-statistic is no longer t-distributed, it becomes skewed.
  • t (df = 2) (heavy tails): now there are too few small p-values – the test is conservative and loses power.
  • Increase n: the histogram becomes flat again (CLT, Chapter 6) – but slowly for very skewed data. The two-sample test with equal n is much more robust, because the skewness of the two groups largely cancels.

Idea. Is an observed correlation r different from 0, or could it be chance? H₀: ρ = 0 (no correlation in the population). Test statistic t = r·√(n−2) / √(1−r²), which follows a t-distribution with df = n − 2 under H₀ (for bivariate normal data).
  • True ρ = 0, n = 10: draw several samples – |r| = 0.4 or more happens often by chance. The right plot shows how large |r| must be to be significant.
  • ρ = 0.3, n = 10 vs. n = 100: same true correlation, but only the large sample reliably gives a significant result (use "Repeat 2000×" for the power).
  • ρ = 0.1, n = 500: significant, but r² ≈ 1% of the variance explained. Significance ≠ relevance.
  • ρ = 0, n = 15, tick "add one outlier": a single point can create a significant Pearson correlation. Switch to Spearman (rank-based) – it is much less affected.
