Basics in Coding

This page is a quick-reference for the coding basics covered in Week 1, plus a short introduction to dplyr / pandas (data manipulation) and ggplot2 / seaborn (plotting). Keep it open in a browser tab while working through the markdowns. Use the language toggle above to switch between R and Python.

Variables & Assignments

Assigning values

Use <- or = to assign a value to a variable. R is case-sensitive — hello and Hello are different objects.

a   <- 2            # numeric
b   <- TRUE         # logical
name <- "Rosalinde" # character (string)

a + 3               # use in calculations: returns 5
print(name)         # explicitly print to console
Function What it does
str(x) Show structure and type of x
ls() List all objects in the environment
rm(x) Remove variable x from the environment
load("file.RData") Reload a saved environment

Vectors

Creating & accessing vectors

A vector is a sequence of values of the same type. When you mix types, R converts everything to the lowest common type (logical → numeric → character).

y <- c(9, 3, 7, 2)   # numeric vector of length 4
length(y)             # 4

# Indexing
y[3]          # 7        — third element
y[2:4]        # 3 7 2    — elements 2 to 4
y[-2]         # 9 7 2    — all except element 2
y[y < 5]      # 3 2      — elements where condition is TRUE

# Logical tests (applied to each element)
y < 5         # FALSE TRUE FALSE TRUE
sum(y < 5)    # 2  — count of elements satisfying condition

# Modifying
y[1] <- 10    # replace first element
TRUE / FALSE in arithmetic: R treats TRUE as 1 and FALSE as 0. So sum(c(TRUE, FALSE, TRUE, TRUE)) = 3 — a quick way to count matching elements.

Matrices

Creating & accessing matrices

A matrix is a 2-dimensional structure. All elements must be the same type. Indexing uses [row, column] — leave one side empty to select all.

X <- matrix(1:6, nrow = 2, ncol = 3, byrow = TRUE)
#      [,1] [,2] [,3]
# [1,]    1    2    3
# [2,]    4    5    6

dim(X)        # c(2, 3)  — rows, then columns
X[1, 2]       # 2        — row 1, column 2
X[2, ]        # 4 5 6    — entire second row
X[, 1]        # 1 4      — entire first column

# Building from vectors
A <- cbind(c(1,2), c(3,4), c(5,6))   # join as columns
B <- rbind(c(1,2,3), c(4,5,6))       # join as rows

# Naming
rownames(A) <- c("r1", "r2")
colnames(A) <- c("p1", "p2", "p3")
Function What it does
dim(X) Returns c(rows, columns)
nrow(X) / ncol(X) Number of rows / columns
cbind(x, y) Combine vectors as columns
rbind(x, y) Combine vectors as rows
colnames(X) Get or set column names
rownames(X) Get or set row names

Lists

Creating & accessing lists

Lists can hold elements of different types and lengths — unlike vectors or matrices. Access elements with $name or [[ ]].

L <- list(color = c("blue", "red"), size = 5, active = TRUE)

# Accessing content (returns the actual value)
L$color           # "blue" "red"
L[["color"]]      # same — "blue" "red"
L[["color"]][2]   # "red"

# Single brackets return a list, not the content
L["color"]        # a list of length 1 (not the vector!)
length(L["color"])   # 1
length(L[["color"]]) # 2

# Modifying & deleting
L[["size"]] <- 10     # change an element
L[["new"]]  <- "hi"   # add a new element
L[[3]] <- NULL         # delete third element
[ ] vs [[ ]]: Single brackets always return a list. Double brackets return the content. Use [[ ]] when you want to work with the value.

Dataframes

Creating & accessing dataframes

A dataframe is like a table: rows are observations, columns are variables. Unlike matrices, different columns can have different types.

Name   <- c("Ben", "Alice", "Daniel", "Charlie")
Year   <- c(1990, 1992, 1995, 1993)
Option <- c("Biology", "Physics", "Chemistry", "Mathematics")

df <- data.frame(First_Name = Name, Year = Year, Options = Option)

# Accessing columns
df$Year           # 1990 1992 1995 1993
df[["Year"]]      # same
df[, 2]           # same — all rows, column 2

# Accessing elements
df$Options[3]     # "Chemistry"
df[2:3, 3]        # "Physics" "Chemistry"

# Merging two dataframes
Full_Names <- data.frame(First_Name = c("Alice","Ben"),
                         Last_Name  = c("Parker","James"))

merge(df, Full_Names)          # Inner join — only matching rows
merge(df, Full_Names, all=TRUE) # Outer join — all rows, NA for missing
Function What it does
data.frame(...) Create a dataframe from named vectors
as.data.frame(X) Convert a matrix to a dataframe
dim(df) Rows and columns
colnames(df) Column names
str(df) Structure overview (types, first values)
merge(a, b) Join two dataframes on shared columns

Loops & Iteration

apply family & for loops

Mat <- matrix(rnorm(12), nrow = 3)

apply(Mat, 1, mean)   # mean of each ROW    (MARGIN = 1)
apply(Mat, 2, mean)   # mean of each COLUMN (MARGIN = 2)

x <- c(1:5)
sapply(x, sqrt)       # apply sqrt() to each element → returns vector
lapply(x, sqrt)       # same but returns a list

# For loop
for (i in 1:4) {
  print(i * 3)
}

# If / else
a <- 5; b <- 10
if (a < b) { print("a is smaller") } else { print("b is smaller") }
Function What it does
apply(X, 1, fun) Apply fun to each row of matrix/dataframe
apply(X, 2, fun) Apply fun to each column
sapply(x, fun) Apply fun to each element of vector/list → vector
lapply(x, fun) Apply fun to each element → list

Index Selection

which, %in%, is.na

x <- c(2, 8, 3, 7, 1)

which(x > 5)          # c(2, 4)  — INDICES where condition is TRUE
x[which(x > 5)]       # c(8, 7)  — VALUES at those indices

c("a","b","c") %in% c("b","d")  # FALSE TRUE FALSE
                                 # — is each element in the right-hand set?

is.na(c(1, NA, 3))    # FALSE TRUE FALSE
sum(is.na(x))         # count of NA values
Function / Operator What it does
which(condition) Returns indices where condition is TRUE
x %in% y For each element of x: is it anywhere in y?
is.na(x) TRUE for each NA element
na.omit(x) Remove NA values from a vector or dataframe

dplyr: Data Manipulation

The core verbs & the pipe

dplyr provides a small set of verbs to work on dataframes. Each verb takes a dataframe as first argument and returns a new dataframe. Column names are written without quotes and without df$. Install once with install.packages("dplyr"), then load it in every session.

library(dplyr)

head(iris)    # built-in data set: 150 flowers, 3 species

# filter(): keep ROWS that satisfy a condition
filter(iris, Species == "setosa")
filter(iris, Sepal.Length > 7, Species != "setosa")   # comma = AND

# select(): keep COLUMNS
select(iris, Sepal.Length, Species)
select(iris, -Petal.Width)           # all columns except Petal.Width

# arrange(): sort rows
arrange(iris, desc(Sepal.Length))    # largest first

# mutate(): add or change columns
mutate(iris, Sepal.Ratio = Sepal.Length / Sepal.Width)
Function What it does
filter(df, cond) Keep the rows where the condition is TRUE
select(df, a, b) Keep (or with -a drop) columns
arrange(df, a) Sort rows by a (use desc(a) for descending)
mutate(df, new = ...) Create a new column or modify an existing one
rename(df, new = old) Rename a column
distinct(df, a) Unique values (rows) of a
The pipe |>: x |> f(y) means f(x, y) — read it as "and then". It lets you chain several steps without nesting functions or creating temporary variables. |> is built into R (≥ 4.1); the older %>% (loaded with dplyr) works the same way.

Group, summarise & join

group_by() splits the data into groups, and summarise() then computes one row per group. This replaces many sapply()/apply() loops.

iris |>
  group_by(Species) |>
  summarise(n           = n(),
            mean_length = mean(Sepal.Length),
            sd_length   = sd(Sepal.Length))

count(iris, Species)      # shortcut: number of rows per group

# A typical chain: filter -> new column -> summary
iris |>
  filter(Sepal.Length > 5) |>
  mutate(Sepal.Ratio = Sepal.Length / Sepal.Width) |>
  group_by(Species) |>
  summarise(mean_ratio = mean(Sepal.Ratio))

# Joining two dataframes (df and Full_Names from the Dataframes section)
left_join(df, Full_Names, by = "First_Name")   # keep all rows of df
inner_join(df, Full_Names, by = "First_Name")  # keep only matching rows
Function What it does
group_by(df, a) Split the data into groups defined by a
summarise(df, m = mean(x)) Collapse each group to one row of summary values
n() Number of rows in the current group (inside summarise/mutate)
count(df, a) Number of rows per value of a
left_join(a, b, by = "id") Add the columns of b to a, matching on id
inner_join(a, b, by = "id") Keep only rows present in both
Tip: the result of summarise() is again a dataframe, so you can pass it straight into ggplot() (next section) or save it with result <- ....

ggplot2: Plotting

Building a plot in layers

A ggplot2 plot is built layer by layer, joined with +: first the data and the aesthetic mapping aes() (which column goes on which axis / colour), then one or more geoms that draw the data, then optional labels, scales and themes.

library(ggplot2)

# Scatter plot, coloured by species
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width, color = Species)) +
  geom_point() +
  labs(x = "Sepal length (cm)", y = "Sepal width (cm)", title = "Iris sepals")

# Other common plot types
ggplot(iris, aes(x = Sepal.Length)) + geom_histogram(bins = 20)
ggplot(iris, aes(x = Species, y = Sepal.Length)) + geom_boxplot()
ggplot(iris, aes(x = Sepal.Length, fill = Species)) + geom_density(alpha = 0.5)

# One panel per species
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width)) +
  geom_point() +
  facet_wrap(~ Species)

# Reference line + own colours
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width, color = Species)) +
  geom_point() +
  geom_vline(xintercept = mean(iris$Sepal.Length), linetype = "dashed") +
  scale_color_manual(values = c(setosa = "#C61826", versicolor = "#590D08", virginica = "#4A4743")) +
  theme_minimal()

# dplyr + ggplot2: summarise first, then plot
iris |>
  group_by(Species) |>
  summarise(mean_length = mean(Sepal.Length)) |>
  ggplot(aes(x = Species, y = mean_length)) +
  geom_col()

ggsave("plot.png", width = 6, height = 4)   # saves the last plot
Function What it does
ggplot(data, aes(x, y)) Start a plot: data and aesthetic mapping
geom_point() / geom_line() Points / lines
geom_histogram() / geom_density() Distribution of one variable
geom_boxplot() Boxplot per group
geom_col() / geom_bar() Bars from a value column / from counts
geom_vline() / geom_hline() Vertical / horizontal reference line
facet_wrap(~ a) One panel per value of a
labs(x, y, title) Axis labels and title
scale_color_manual(values = ...) Choose your own colours
theme_minimal() Clean look (also theme_bw(), theme_classic())
ggsave("file.png") Save the last plot to a file
Two common mistakes: (1) the + must be at the end of a line, not at the start of the next one. (2) Variables from your data go inside aes() (aes(color = Species)); a fixed value goes outside (geom_point(color = "red")). Also remember that ggplot() needs a dataframe, not a bare vector.

Variables & Assignments

Assigning values

Use = to assign a value to a variable. Python is case-sensitive — hello and Hello are different objects. There is no <- operator in Python.

a    = 2              # integer
b    = True           # boolean  (note capital T)
name = "Rosalinde"   # string

a + 3                # 5
print(name)          # Rosalinde
Function What it does
type(x) Show the type of x
dir() List all names in the current scope
del x Remove variable x

Lists

Creating & accessing lists (R: vectors)

Python lists use 0-based indexing and can hold mixed types. Use [ ] for indexing and slicing.

y = [9, 3, 7, 2]    # list of length 4
len(y)               # 4

# Indexing (0-based!)
y[2]                 # 7        — third element (index 2)
y[1:3]               # [3, 7]   — elements at index 1 and 2
y[:-1]               # [9,3,7]  — all except last

# Filter with list comprehension
[x for x in y if x < 5]      # [3, 2]
[x < 5 for x in y]           # [False, True, False, True]
sum(x < 5 for x in y)        # 2  — count matching

# Modifying
y[0] = 10            # replace first element (index 0)
Mixed types: Unlike R vectors, Python lists allow mixed types: [True, "hello", 3] stays as-is — no automatic conversion. Indexing starts at 0, not 1.

NumPy Arrays

Creating & accessing arrays (R: matrices)

NumPy arrays are the Python equivalent of R matrices. Requires import numpy as np. Indexing is 0-based.

import numpy as np

X = np.array([[1, 2, 3],
              [4, 5, 6]])
# Shape: (2, 3)

X.shape          # (2, 3)  — rows, then columns
X[0, 1]          # 2       — row 0, column 1 (0-based!)
X[1, :]          # [4 5 6] — entire second row
X[:, 0]          # [1 4]   — entire first column

# Building from vectors
A = np.column_stack(([1,2], [3,4], [5,6]))  # join as columns
B = np.vstack([[1,2,3], [4,5,6]])            # join as rows
Function What it does
X.shape Returns (rows, columns) as a tuple
X.reshape(r, c) Reshape to r rows and c columns
np.hstack((a, b)) Combine arrays side by side (columns)
np.vstack((a, b)) Stack arrays vertically (rows)

Dictionaries

Creating & accessing dicts (R: lists)

Dictionaries hold key–value pairs of any type. Use [ ] with the key to access values — there is no $ or [[ ]] in Python.

L = {"color": ["blue", "red"], "size": 5, "active": True}

# Accessing content
L["color"]           # ["blue", "red"]
L["color"][1]        # "red"   — second element (0-based)

# Check if key exists
"color" in L         # True

# Modifying & deleting
L["size"] = 10       # change a value
L["new"]  = "hi"     # add a new key
del L["size"]        # delete a key
R vs Python: R's L[["color"]] → Python's L["color"]. Square brackets always return the value directly in Python — no double-bracket distinction.

DataFrames

Creating & accessing DataFrames (R: data.frame)

Pandas DataFrames are the Python equivalent of R dataframes. Requires import pandas as pd.

import pandas as pd

Name   = ["Ben", "Alice", "Daniel", "Charlie"]
Year   = [1990, 1992, 1995, 1993]
Option = ["Biology", "Physics", "Chemistry", "Mathematics"]

df = pd.DataFrame({"First_Name": Name, "Year": Year, "Options": Option})

# Accessing columns
df["Year"]            # Series: 1990 1992 1995 1993
df.Year               # same — attribute-style access
df.iloc[:, 1]         # same — all rows, column index 1 (0-based)

# Accessing elements
df["Options"].iloc[2]    # "Chemistry"
df.iloc[1:3, 2]          # "Physics", "Chemistry"

# Merging two DataFrames
Full_Names = pd.DataFrame({"First_Name": ["Alice","Ben"],
                            "Last_Name":  ["Parker","James"]})

pd.merge(df, Full_Names)                    # Inner join — matching rows only
pd.merge(df, Full_Names, how="outer")       # Outer join — all rows, NaN for missing
Function What it does
pd.DataFrame({...}) Create a DataFrame from a dict of lists
df.shape Rows and columns as (r, c)
df.columns Column names
df.dtypes Data type of each column
df.describe() Summary statistics for numeric columns
pd.merge(a, b) Join two DataFrames on shared columns

Loops & Iteration

for loops, list comprehensions & numpy

import numpy as np

Mat = np.random.randn(3, 4)

np.mean(Mat, axis=0)        # mean of each COLUMN
np.mean(Mat, axis=1)        # mean of each ROW

x = list(range(1, 6))       # [1, 2, 3, 4, 5]
[np.sqrt(i) for i in x]     # list comprehension — apply to each element
list(map(np.sqrt, x))        # same result with map()

# For loop
for i in range(1, 5):
    print(i * 3)

# If / else
a = 5; b = 10
if a < b:
    print("a is smaller")
else:
    print("b is smaller")
Function / Syntax What it does
np.mean(X, axis=0) Mean of each column (axis 0 = rows collapse)
np.mean(X, axis=1) Mean of each row (axis 1 = columns collapse)
[f(x) for x in lst] List comprehension — apply f to each element
map(f, lst) Apply f to each element → map object
filter(f, lst) Keep elements where f returns True

Index Selection

np.where, in, pd.isna

import numpy as np
import pandas as pd

x = np.array([2, 8, 3, 7, 1])

np.where(x > 5)          # (array([1, 3]),)  — INDICES where condition is TRUE
x[np.where(x > 5)]       # array([8, 7])     — VALUES at those indices
x[x > 5]                 # array([8, 7])     — direct boolean indexing (shortcut)

"a" in ["b", "d"]        # False  — membership test
["a" in ["b","d"], "b" in ["b","d"], "c" in ["b","d"]]  # [False, True, False]

pd.isna(pd.Series([1, None, 3]))   # [False, True, False]
np.isnan(x.astype(float))          # array of bool (for float arrays)
Function / Operator What it does
np.where(condition) Returns tuple of indices where condition is TRUE
x in y True if x appears in sequence y
pd.isna(x) True for each NaN / None element
np.isnan(x) True for each NaN in a NumPy float array
df.dropna() Remove rows with any missing value

pandas: Data Manipulation (R: dplyr)

Filter, select, sort, new columns, group & summarise

pandas does everything R’s dplyr does. Here the column names are strings and you work with the DataFrame methods (df.method()). The example uses the iris data set that ships with seaborn.

import pandas as pd
import seaborn as sns

iris = sns.load_dataset("iris")   # columns: sepal_length, sepal_width, petal_length, petal_width, species
iris.head()

# filter: keep ROWS that satisfy a condition   (R: filter)
iris[iris["species"] == "setosa"]
iris.query("sepal_length > 7 and species != 'setosa'")    # same idea, readable text condition

# select: keep COLUMNS                         (R: select)
iris[["sepal_length", "species"]]
iris.drop(columns="petal_width")                          # all columns except petal_width

# sort                                          (R: arrange)
iris.sort_values("sepal_length", ascending=False)

# new column                                    (R: mutate)
iris.assign(sepal_ratio = iris["sepal_length"] / iris["sepal_width"])

# group + summarise                             (R: group_by + summarise)
iris.groupby("species").agg(n           = ("species", "size"),
                            mean_length = ("sepal_length", "mean"),
                            sd_length   = ("sepal_length", "std"))

iris["species"].value_counts()                            # (R: count)

# Chain several steps with parentheses            (R: the |> pipe)
(iris
   .query("sepal_length > 5")
   .groupby("species")
   .agg(mean_length=("sepal_length", "mean"))
   .reset_index())
Function What it does (R equivalent)
df[df["a"] > 5] / df.query("a > 5") Keep rows matching a condition (filter)
df[["a", "b"]] / df.drop(columns="a") Keep / drop columns (select)
df.sort_values("a") Sort rows (arrange)
df.assign(new = ...) Add or change a column (mutate)
df.rename(columns={"old": "new"}) Rename a column (rename)
df.groupby("a").agg(m=("x", "mean")) Group and summarise (group_by + summarise)
df["a"].value_counts() Number of rows per value (count)
pd.merge(a, b, on="id", how="left") Join two DataFrames (left_join)
.reset_index() Turn the group labels back into a normal column
Tip: most pandas methods return a new DataFrame and leave the original unchanged. Save the result (result = iris.query(...)) if you want to keep it. After groupby().agg() the group names sit in the index — .reset_index() moves them back into a column.

Plotting: matplotlib & seaborn (R: ggplot2)

Quick plots with seaborn, fine-tuning with matplotlib

seaborn draws statistical plots directly from a DataFrame (like ggplot2); matplotlib (plt) is the layer underneath, used for labels, titles, reference lines and saving. In seaborn you pass data= and the column names for x, y and hue (= colour groups, like color/fill in aes()).

import matplotlib.pyplot as plt
import seaborn as sns

# Scatter plot, coloured by species
sns.scatterplot(data=iris, x="sepal_length", y="sepal_width", hue="species")
plt.xlabel("Sepal length (cm)")
plt.ylabel("Sepal width (cm)")
plt.title("Iris sepals")
plt.show()

# Other common plot types
sns.histplot(data=iris, x="sepal_length", bins=20)
sns.boxplot(data=iris, x="species", y="sepal_length")
sns.kdeplot(data=iris, x="sepal_length", hue="species", fill=True, alpha=0.5)

# One panel per species                          (R: facet_wrap)
sns.relplot(data=iris, x="sepal_length", y="sepal_width", col="species")

# Reference line + own colours
sns.scatterplot(data=iris, x="sepal_length", y="sepal_width", hue="species",
                palette={"setosa": "#C61826", "versicolor": "#590D08", "virginica": "#4A4743"})
plt.axvline(iris["sepal_length"].mean(), linestyle="--")

# dplyr-style summary first, then plot
means = iris.groupby("species").agg(mean_length=("sepal_length", "mean")).reset_index()
sns.barplot(data=means, x="species", y="mean_length")

plt.savefig("plot.png", dpi=300, bbox_inches="tight")   # call BEFORE plt.show()
Function What it does (R equivalent)
sns.scatterplot(data, x, y, hue) Scatter plot (geom_point)
sns.lineplot(...) Line plot (geom_line)
sns.histplot() / sns.kdeplot() Histogram / density (geom_histogram, geom_density)
sns.boxplot() Boxplot per group (geom_boxplot)
sns.barplot() Bars of a mean (or other estimate) per group (geom_col)
sns.relplot(..., col="a") One panel per value of a (facet_wrap)
plt.axvline() / plt.axhline() Vertical / horizontal reference line (geom_vline / geom_hline)
plt.xlabel() / plt.ylabel() / plt.title() Axis labels and title (labs)
plt.savefig("file.png") Save the figure (ggsave)
Tip: if you prefer the ggplot2 syntax (ggplot(...) + geom_point()) in Python, the optional package plotnine offers it. In this course we use matplotlib and seaborn, as in the Python notebooks.
